# 🔎 PayStream Payment Failure Analysis

## 📌 Analysis Overview

This section contains the analysis work completed during the PayStream Payment Failure Analysis project.

The purpose of the analysis was to investigate payment failures, identify changes in payment performance over time, compare different merchant and payment categories, and identify possible causes behind the increase in failed transactions.

## 🧹 1. Data Preparation

Before carrying out the analysis, the datasets were reviewed to identify data quality issues that could affect the results.

The checks included:

- Missing values
- Duplicate records
- Inconsistent data
- Incorrect or unusual values
- Data quality issues that could affect the reliability of the analysis

The cleaned data was then prepared for further analysis.

## 📊 2. Payment Performance Analysis

Payment transaction data was analysed to understand how payment performance changed across the period.

The analysis focused on:

- Payment success and failure patterns
- Differences between merchant categories
- Differences between payment categories
- Changes in payment performance over time

## 📈 3. Trend Analysis

Weekly payment performance was reviewed to identify significant changes and periods of deterioration.

A noticeable deterioration was identified around **Weeks 9–12**, which became an important area for further investigation.

## 🔍 4. Root Cause Investigation

The transaction analysis was combined with the supporting project documentation to investigate potential causes of the increase in payment failures.

This included reviewing the payment process and the timing of the **Billing Validation Rule (BVR)** engineering change.

The investigation helped connect changes in payment performance with relevant business and technical information.

## 💡 Key Findings

- Payment performance changed noticeably during the period analysed.
- A significant deterioration was identified around Weeks 9–12.
- Some merchant and payment categories experienced higher failure levels than others.
- Data quality checks were important for ensuring reliable analysis.
- The results highlighted areas requiring further investigation and monitoring.
