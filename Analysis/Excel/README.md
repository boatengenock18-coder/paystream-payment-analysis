# PayStream Payment Analysis – Excel

## Overview

Microsoft Excel was used during the initial stage of this project to explore, validate, and prepare the PayStream payment transaction dataset before importing it into SQL and Power BI.

## Workbook Contents

### Raw Data
- Original payment transaction dataset imported from the CSV file.

### Data Cleaning
- Reviewed the dataset for missing values.
- Checked for duplicate records.
- Validated data types.
- Confirmed the dataset was ready for analysis.

### Analysis Summary
- Summarised key performance metrics.
- Identified the overall payment failure rate.
- Highlighted the highest-risk payment method and merchant type.
- Documented the main trend identified during the analysis.
