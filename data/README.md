# PayStream Project Data

This folder contains the dataset used for the PayStream Payment Failure Analysis project.

The data was used to investigate payment performance, identify data quality issues, analyse payment failure patterns, and examine changes in performance over time.

## Data Preparation

Before analysis, the dataset was reviewed for:

- Missing values
- Duplicate records
- Inconsistent data
- Incorrect or unusual values
- Data quality issues that could affect the analysis

The cleaned data was then used for further analysis and visualisation in Excel and Power BI.
