# 📚 PayStream Project Documentation

This folder contains the supporting business and technical documentation used during the PayStream Payment Failure Analysis project.

The documentation provided important context for understanding the payment failure problem, business processes, system terminology, and the engineering changes that contributed to the increase in failed transactions.

## 📄 Documentation Included

### Company Brief
Provides background information about PayStream, the business problem, project objectives, stakeholders, and the payment failure investigation.

### Process Notes
Documents the payment processing workflow and supporting information used to understand potential causes of payment failures.

### Project Glossary
Provides definitions of important business, payment, and technical terminology used throughout the project.

### Engineering Sprint Plan
Documents the Billing Validation Rule (BVR) change and deployment timeline. This information supported the root cause investigation into the increase in payment failures.

## 🎯 Purpose

These documents were used alongside the transaction datasets to provide business context and support the analysis, root cause investigation, findings, and recommendations.

> This repository is presented as a portfolio project demonstrating my data analysis and business analysis skills.
